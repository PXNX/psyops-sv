## CORE TABLES

### AUTH & USERS
**accounts** (id text PK): email, role, createdAt, updatedAt
**userProfiles** (id int PK): accountId FK→accounts (unique), name, logo FK→files, bio
**sessions** (id text PK): accountId FK→accounts, expiresAt, createdAt
**oauthTokens** (id int PK): accountId FK→accounts (unique), provider, accessToken, refreshToken, tokenExpiresAt
**userWallets** (id int PK): userId FK→accounts (unique), balance (default 10000), updatedAt
**files** (id int PK): key (unique), fileName, contentType, sizeBytes, uploadedBy FK→accounts, uploadedAt

### GEOGRAPHY
**blocs** (id int PK): name (unique), logo FK→files, color, description, capitulated, capitulated_at, createdAt
**states** (id int PK): name, logo FK→files, background, description, population, rating, capitulated, capitulated_at, blocId FK→blocs, createdAt
**regions** (id int PK): latitude, longitude, stateId FK→states, rating, infrastructure, economy, education, hospitals, fortifications, oil, aluminium, rubber, tungsten, steel, chromium, createdAt
**regionBorders** (id int PK): regionId FK→regions, neighborId FK→regions, distanceKm. Unique(regionId, neighborId), Check(regionId < neighborId)
**stateBorders** (id int PK): stateId FK→states (unique), status, maintenanceCostPerDay (50000), lastMaintenancePaid, closedBy FK→accounts, closedAt, updatedAt

### RESIDENCY & TRAVEL
**residences** (id int PK): userId FK→accounts (unique), regionId FK→regions, movedInAt
**residenceApplications** (id int PK): userId FK→accounts, regionId FK→regions, status (pending), appliedAt, reviewedAt, reviewedBy FK→accounts, reviewNote
**userTravels** (id int PK): userId FK→accounts (unique), fromRegionId FK→regions, toRegionId FK→regions, departureTime, arrivalTime, travelDuration, status, distanceKm, createdAt

### POLITICS
**presidents** (id int PK): userId FK→accounts, stateId FK→states (unique), electedAt, term
**governors** (id int PK): userId FK→accounts, regionId FK→regions (unique), appointedAt, term
**ministers** (id int PK): userId FK→accounts, stateId FK→states, ministry, appointedAt. Unique(userId, stateId, ministry), Unique(stateId, ministry)
**politicalParties** (id int PK): name (unique), abbreviation, color, logo FK→files, ideology, description, founderId FK→accounts, stateId FK→states, foundedAt, autoAcceptMembers
**partyMembers** (id int PK): userId FK→accounts, partyId FK→politicalParties, role (member), joinedAt, acceptedBy FK→accounts. Unique(userId, partyId)
**partyMembershipApplications** (id int PK): userId FK→accounts, partyId FK→politicalParties, status (pending), appliedAt, reviewedBy FK→accounts, reviewedAt, reviewNote
**parliamentMembers** (id int PK): userId FK→accounts, stateId FK→states, partyAffiliation, electedAt, term. Unique(userId, stateId)

**parliamentaryProposals** (id int PK): stateId FK→states, proposalType, proposedBy FK→accounts, status (active), votingStartsAt, votingEndsAt, requiredMajority (50), createdAt

## KEY MECHANICS

**Battle System (HoI4-inspired)**:
- Phases: preparation (join) → planning (combat starts, bonus builds) → active (full combat) → ended
- Combat width: Limited units engage (isEngaged flag)
- Organization: 0-100, drops in combat, exhausted units ineffective
- Planning bonus: Builds during planning, applied in active phase
- Terrain modifiers affect combat

**Economy**: Resources → Factories (with workers) → Products → Market (player trading)

**Politics**: Elections → Parliament → Proposals (tax/infrastructure) → Voting → Implementation

**Immigration**: Visas required by some states, border control (open/closed with maintenance cost)

**Unique Constraints**: One per user: residence, wallet, factory job, production queue, travel, chat restriction, profile

## QUERY PATTERNS
- User dashboard: profile + wallet + residence + employment + politics
- State view: info + president + treasury + energy + regions + parties + proposals
- Battle view: battle + war + participants + rounds + planning bonuses
- Market view: listings + statistics + price history + user inventory
- Moderation: pending reports + warnings + restrictions + flags
