# Häufige Fragen

## Wie fange ich an?

Folgen Sie der [Einführung](/docs/intro). Nach der Registrierung wählen Sie eine
Region und schließen das Onboarding ab.

## Wie verdiene ich Geld?

Arbeiten Sie in einer **Fabrik**, verkaufen Sie Waren auf dem **Markt** oder
gründen Sie ein eigenes **Unternehmen**.

## Wie werde ich politisch aktiv?

Treten Sie einer **Partei** bei, kandidieren Sie bei **Wahlen** und bringen Sie
eigene **Vorschläge** ein.

## Ich habe einen Fehler gefunden – was nun?

Nutzen Sie die Melde-Funktion in der App, damit unser Team das Problem prüfen
kann. Geben Sie dabei möglichst viele Details an.
